This pull request modifies the definition of `CFE_MSG_Message_t` from a `union` to a `struct`, and updates related code that accesses the message data. This change affects how the message structure is interpreted in memory and how its contents are accessed. Here's an analysis of potential impacts on other repositories and files:

### Key Changes:
1. **`cfe_msg_api_typedefs.h`**: Changed `typedef union CFE_MSG_Message CFE_MSG_Message_t;` to `typedef struct CFE_MSG_Message CFE_MSG_Message_t;`
2. **`default_cfe_msg_hdr_pri.h` and `default_cfe_msg_hdr_priext.h`**: Updated the definition of `CFE_MSG_Message` from a `union` to a `struct`, removing the `Byte` member.
3. **`cfe_sb_handlers.c`**: Updated access to `MsgPtr->Byte[0]` to `*BytePtr & 0x10` where `BytePtr` is cast from `MsgPtr`.
4. **`ut_support.c`**: Updated `memcpy` and `UT_DisplayPkt` to use `(uint8 *)MsgPtr` instead of `MsgPtr->Byte`.
5. **`cfe_msg_sechdr_checksum.c`**: Cast `MsgPtr` to `(const uint8 *)` for byte-level access.
