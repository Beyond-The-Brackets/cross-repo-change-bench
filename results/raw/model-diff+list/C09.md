This PR fundamentally restructures the message handling logic related to header updates and integrity checks within the cFE core. It replaces the `CFE_MSG_UpdateHeader` function with two new functions: `CFE_MSG_OriginationAction` and `CFE_MSG_VerificationAction`. It also renames the `UpdateHeader` parameter in `CFE_SB_TransmitMsg` and `CFE_SB_TransmitBuffer` to `IsOrigination`.

The primary goal seems to be separating the concerns of:
1.  **Origination Actions:** What needs to happen when a message is *first created* and *sent out* (like setting sequence numbers, timestamps, generating checksums).
2.  **Verification Actions:** What needs to happen when a message is *received* and needs to be checked for validity (which might be a no-op in the default implementation but allows for future expansion).
