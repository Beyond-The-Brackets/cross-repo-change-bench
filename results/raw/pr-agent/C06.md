**Version API Changes**

The PSP version APIs now rely on `CFE_PSP_IMPL_*` macros defined in `psp_version.h` instead of accessing `GLOBAL_PSP_CONFIGDATA`. This change removes the dependency on the global config data structure, which aligns with the PR's intent to eliminate the global object. However, it assumes that the `psp_version.h` files in each PSP implementation correctly define these macros, and that the build system properly includes them.



**Removed Version Macros**

The version macros (`CFE_PSP_MAJOR_VERSION`, `CFE_PSP_MINOR_VERSION`, etc.) have been removed from `cfe_psp.h`. These macros were previously defined using fields from `GLOBAL_PSP_CONFIGDATA`. Their removal means that any code relying on these macros directly will need to be updated to use the new approach via `psp_version.h`.
